# 楷书字帖练习

一个基于React的在线楷书字帖生成工具，帮助书法爱好者练习硬笔书法。

## 功能特点

### 多种字体选择
- **硬笔楷书**：霞鹜文楷、霞鹜文楷屏幕版、霞鹜文楷等宽
- **传统楷书**：系统楷体
- **可爱风格**：站酷小薇、站酷快乐体、龙藏体、芝忙行

### 灵活的练习模式
- 支持**多行输入**，可练习古诗词、课文等内容
- 每个字可设置**1-8次**练习次数
- **田字格**和**米字格**两种格式可选
- 范字显示清晰，辅助线帮助定位

### 便捷的操作
- 内置45个常用汉字快速选择
- 支持**打印功能**，可导出纸质字帖
- 响应式设计，支持手机和电脑

## 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

访问 http://localhost:3000 即可使用

### 构建生产版本
```bash
npm run build
```

## 使用方法

1. **输入汉字**：在文本框中输入要练习的汉字，支持多行输入（按回车换行）
2. **选择字体**：从下拉菜单中选择喜欢的字体风格
3. **设置参数**：
   - 练习次数：每个字的练习遍数（1-8次）
   - 格子类型：田字格或米字格
4. **开始练习**：查看生成的字帖，第一个格子为范字，其余为空白练习格
5. **打印字帖**：点击"打印字帖"按钮导出纸质版本

## 技术栈

- **前端框架**：React 18
- **构建工具**：Vite
- **字体资源**：
  - LXGW WenKai（霞鹜文楷）
  - Google Fonts（站酷系列字体）

## 字体说明

| 字体名称 | 风格特点 | 适用场景 |
|---------|---------|---------|
| 霞鹜文楷 | 清秀规整，接近手写 | 日常练习、作业 |
| 霞鹜文楷屏幕版 | 笔画更清晰 | 屏幕显示 |
| 霞鹜文楷等宽 | 等宽排列 | 对齐练习 |
| 系统楷体 | 传统楷书风格 | 传统字帖 |
| 站酷小薇 | 清秀可爱，笔画柔和 | 女生练字、日记 |
| 站酷快乐体 | 活泼圆润，充满童趣 | 儿童练字、贺卡 |
| 龙藏体 | 可爱手写风，自然流畅 | 创意书写、手账 |
| 芝忙行 | 趣味手写，个性十足 | 艺术创作、签名设计 |
